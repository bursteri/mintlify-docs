## How to read this changelog

- Each page summarizes one release day rather than one pull request.
- Customer-visible behavior and meaningful platform improvements are included.
- Formatting, CI-only maintenance, and unsigned draft work are omitted.
- Breaking developer-contract changes are called out explicitly.
