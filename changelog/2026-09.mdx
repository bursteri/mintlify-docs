PlainRouter ships continuously. This page collects the customer-facing changes from September and leaves out formatting, CI, and internal draft work.

<Update label="September 2, 2026">

  ## SDK and CLI packages link to canonical documentation

  **Improved** · TypeScript SDK [`@plainrouter/sdk@0.5.1`](https://www.npmjs.com/package/@plainrouter/sdk), npm CLI [`@plainrouter/cli@0.5.1`](https://www.npmjs.com/package/@plainrouter/cli), Python SDK and CLI [`plainrouter==0.5.2`](https://pypi.org/project/plainrouter/), and Ruby gem [`plainrouter-sdk 0.1.1`](https://rubygems.org/gems/plainrouter-sdk) now publish canonical `plainrouter.com/docs` links in their package metadata or README. The releases continue to target signed API contract `0.5.0`. [Choose an official client](/reference/conversion-api#client-releases).
