## Choose one purchase sender

Start with an active [Signal](/quickstart). Advertising delivery also requires a [connected Meta dataset](/signals/connect-meta) and a recorded consent decision. Select one owner for each logical purchase; enabling multiple senders for the same checkout can create duplicates.

| Your integration | Start here | Expected result |
| --- | --- | --- |
| Browser checkout with server-confirmed payment | [Managed browser purchase](/signals/track-events#avoid-duplicate-meta-events) | Signals sends the managed browser/server pair with shared event identity. |
| Backend or job queue | [Node.js and TypeScript recipe](/sdk/recipes/meta-conversions), [Python](/sdk/python#send-a-meta-conversion), or [Ruby](/sdk/ruby#send-a-meta-conversion) | Your backend sends a stable purchase ID and the original payment time through the Conversion API. |
| Stripe Checkout | [Verified Stripe settlement](/signals/track-events#verify-stripe-checkout-settlement) | Records settled revenue without an attributed visitor join or Meta delivery. |

An API receipt confirms ingestion. [Inspect destination delivery](/signals/connect-meta#how-do-i-verify-meta-delivery) to check Meta acceptance; acceptance does not establish attribution or improved advertising performance.

## Set up access and development tools

- [Choose the correct credential](/api/authentication): Signals secrets for REST, SDKs, and CLI; workspace execution tokens for MCP.
- [Try the API sandbox](/api/sandbox): validate synthetic requests without an account or Meta delivery.
- [Choose an SDK or CLI](/sdk/overview), or open the [Conversion API overview](/api/conversions).
- [Read MCP tool inputs and limits](/mcp/tools), then [create a governed creative proposal](/actions/creative-workflow).
- [Review pricing and billing](/billing/overview) before moving from testing to ongoing production use.

Actions defaults to **Suggest only**. Supported creative execution requires policy checks and human approval; budget changes, ad activation, and delivery-status execution are unavailable.

## Legacy Launcher

[Drive inventory](/launcher/connect-drive) and [draft-file import](/launcher/import-draft-batch) apply only where legacy Launcher is explicitly enabled. They are disabled by default and are not prerequisites for Signals or the active Meta creative tools.
