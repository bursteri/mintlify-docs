[`plainrouter`](https://pypi.org/project/plainrouter/) contains the generated Python SDK and the `plainrouter` command-line interface. The SDK exposes synchronous and asynchronous Conversion API operations, with ten convenience imports at the package root. The CLI exposes nine API commands.

The current [PyPI release](https://pypi.org/project/plainrouter/) is `0.5.2` and targets signed API contract `0.5.0`. The source is in [`plainrouter/sdk`](https://github.com/plainrouter/sdk/tree/main/packages/python).

## Requirements

- Python 3.11 or newer.
- A Signals workspace secret.
- Server-side code. Do not put the secret in browser or distributed client code.

## Install

```bash
python -m pip install plainrouter==0.5.2
```

For command-line use, install the package in an isolated environment with [`pipx`](https://pipx.pypa.io/):

```bash
pipx install plainrouter==0.5.2
plainrouter --help
```

You can also run `python -m plainrouter` from an active environment. See the [CLI quickstart](/cli/quickstart) for authentication, configuration, and command examples.

## Create a client

```python
from plainrouter import create_client, list_events

client = create_client("YOUR_SIGNALS_WORKSPACE_SECRET")
response = list_events.sync(client=client)
```

The default API base is `https://plainrouter.com/api/v1` and the default request timeout is 30 seconds.

## Use async operations

Each operation module also provides an asynchronous method:

```python
from plainrouter import create_client, get_event

client = create_client("YOUR_SIGNALS_WORKSPACE_SECRET")
response = await get_event.asyncio(
    event="event-id",
    client=client,
)
```

## Send a Meta conversion

This recipe sends a purchase through Plainrouter to your connected [Meta destination](/signals/connect-meta). Set `PLAINROUTER_SIGNAL_SECRET` in your server environment and run it only when your recorded consent permits advertising use.

Replace the sample order, identity, browser identifiers and timestamps with your actual purchase and consent records. Keep the same event ID and purchase time on retries. Omit browser identifiers when unavailable.

### Send a purchase synchronously

The generated nested consent, identity, and click-ID models accept dictionaries through `from_dict`. This keeps the request readable while preserving the generated top-level event type.

```python
from http import HTTPStatus
import os

from plainrouter import create_client, create_event
from plainrouter.generated.models import CreateEventBodyType0


signal_secret = os.environ["PLAINROUTER_SIGNAL_SECRET"]
client = create_client(signal_secret)

order_id = "ORDER-1042"
event = CreateEventBodyType0.from_dict(
    {
        "event_id": f"purchase:{order_id}",
        "event_name": "Purchase",
        "event_time": 1786272000,
        "event_source": "https://shop.example/checkout/success",
        "action_source": "website",
        "consent_basis": "consent",
        "consent": {
            "ad_storage": "granted",
            "ad_user_data": "granted",
            "ad_personalization": "granted",
            "captured_at": "2026-08-09T12:00:00Z",
            "source": "checkout_cmp",
        },
        "user_data": {
            "email": "buyer@example.com",
            "phone": "+358401234567",
            "client_ip_address": "203.0.113.10",
            "client_user_agent": "ExampleCheckout/1.0",
        },
        "click_ids": {
            "fbp": "fb.1.1786271000000.1234567890",
            "fbc": "fb.1.1786271000000.EXAMPLE_FBCLID",
        },
        "value_data": {
            "value": "49.90",
            "currency": "EUR",
            "order_id": order_id,
            "contents": [{"id": "SKU-1", "quantity": 2}],
            "num_items": 2,
        },
    }
)

response = create_event.sync_detailed(client=client, body=event)

if response.status_code not in {HTTPStatus.OK, HTTPStatus.ACCEPTED}:
    raise RuntimeError(response.content.decode("utf-8"))

if response.parsed is None:
    raise RuntimeError("Plainrouter returned an empty response")

print(
    {
        "event_id": response.parsed.event_id,
        "duplicate": response.parsed.duplicate,
    }
)
```

Replace the example `fbp` and `fbc` values with values captured from the consenting browser. Omit a field when you do not have a valid value; do not send placeholders in production.

Plainrouter normalizes and hashes raw supported identity values before Meta delivery. A 64-character SHA-256 value is accepted as already hashed. Browser identifiers such as `fbp` and `fbc` remain unhashed.

### Send the same model asynchronously

Reuse the event model with the generated async operation:

```python
response = await create_event.asyncio_detailed(client=client, body=event)

if response.status_code not in {HTTPStatus.OK, HTTPStatus.ACCEPTED}:
    raise RuntimeError(response.content.decode("utf-8"))
```

The client reuses an `httpx` session. Create one client per service configuration rather than constructing a new client for every event.

### Retry safely

Use the same `event_id` for every retry of the same purchase. Plainrouter returns:

- HTTP `202` and `duplicate: false` for a new accepted event.
- HTTP `200` and `duplicate: true` for an already accepted event ID.

You can use the generated `idempotency_key` argument instead of a body `event_id`. When both are present, they must match. See [Meta `event_id` deduplication](https://plainrouter.com/library/meta-event-id-deduplication) before pairing this event with a browser Pixel event.

### Confirm Meta delivery

An accepted ingestion response is not a final Meta delivery receipt. Use `get_event.sync` with the returned event ID or read [Signal health and performance](/signals/health-and-performance) to inspect queued, accepted, skipped, and failed delivery states.

## Verify Signal ingestion

```python
from plainrouter import create_client, verify_signal_ingestion

client = create_client("YOUR_SIGNALS_WORKSPACE_SECRET")
response = verify_signal_ingestion.sync(client=client)
```

The operation is idempotent. A repeated verification returns the existing event with `duplicate: true`. The event confirms ledger receipt but is not real arrival evidence and does not complete onboarding.

## Available operation modules

| Module | Purpose |
| --- | --- |
| `create_event` | Submit an idempotent conversion event. |
| `verify_signal_ingestion` | Write an identity-free ingestion diagnostic that does not complete onboarding. |
| `get_event` | Retrieve an event, lineage, and delivery state. |
| `list_events` | List recent events and delivery metrics. |
| `set_destination_test_mode` | Enable or disable destination test mode. |
| `send_test_purchase` | Send a controlled test purchase. |
| `replay_deliveries` | Replay eligible recent deliveries. |
| `get_reconciliation_report` | Retrieve reconciliation results for a date. |
| `get_emq_report` | Retrieve recent Event Match Quality snapshots. |
| `delete_user_data` | Delete data matching a hashed identifier. |

## List events by cursor

Cursor-based listing is available through the generated module rather than a package-root convenience import:

```python
from plainrouter import create_client
from plainrouter.generated.api.operations import list_events_by_cursor

client = create_client("YOUR_SIGNALS_WORKSPACE_SECRET")
response = list_events_by_cursor.sync(client=client, per_page=25)
```

Omit `cursor` on the first request. For the next page, pass the opaque `next_cursor` returned in the response's event pagination data. The CLI does not expose this operation.

## Configure another API origin or timeout

Pass `base_url` or an `httpx.Timeout` when creating the client:

```python
import httpx
from plainrouter import create_client

client = create_client(
    "YOUR_SIGNALS_WORKSPACE_SECRET",
    base_url="https://example.test/api/v1",
    timeout=httpx.Timeout(20.0),
)
```

Override the production origin only for a Plainrouter-provided region or a controlled test environment.

## Handle credentials safely

The Python SDK accepts a Signals workspace secret. It does not accept an MCP workspace execution token or OAuth management credential.

Keep the secret in a server-side secret manager. Never include it in prompts, URLs, logs, source control, or client-side code.

For request and response fields, use the [API reference](/reference/conversion-api).
