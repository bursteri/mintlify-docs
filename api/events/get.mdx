---
title: "Get an event and delivery trace"
description: "Returns one retained customer-readable event with lineage and destination delivery state for scoped troubleshooting and acceptance checks."
openapi: "GET /events/{event}"
---

Event visibility follows the workspace's plan and any explicit shorter setting. Payloads and delivery evidence have separate retention limits. See [event and delivery read windows](/api/conversions#how-far-back-can-i-read-events-and-deliveries).
